# Tekken 1 portraits

`portraits.png` is the original, unmodified 492 × 520 PlayStation portrait sheet.
The UI selects regions using coordinates in `/public/data/tekken-1.json`.

- Game artwork: Namco.
- Sheet extraction: Unstabledproton.
- Archive: https://www.spriters-resource.com/playstation/tekken/asset/78298/
- Download: https://www.spriters-resource.com/media/assets/75/78298.png?updated=1755474281
- Retrieved: 2026-09-16.

Identities were cross-checked against labeled Tekken 1 character-select portraits
in the corresponding Tekkenpedia character galleries, including Kazuya Mishima,
Marshall Law, Michelle Chang, Kunimitsu, Yoshimitsu, Ganryu, Jack and Prototype Jack.
Kunimitsu and Yoshimitsu deliberately share the same original portrait.
No ownership or open-license claim is made for this game artwork.
