# Tekken 3 archive expansion

Expanded the existing character data with selected missing moves, stance attacks, 73 combo entries (shared follow-ups group their launchers), and practical hidden-move notes. Existing routes remain. Duplicate move/unblockable rows are consolidated under Unblockable Attacks.

Sources supplied for this update:

- [Movelist index and linked character pages](https://web.archive.org/web/20201206040254/http://www.tekkenzaibatsu.com/tekken3/_movelist.php)
- [Juggle discussion, first page](https://web.archive.org/web/20201206041650/http://www.tekkenzaibatsu.com/forums/showthread.php?threadid=63332)
- [Hidden moves, consolidated opening post and first-page corrections](https://web.archive.org/web/20201206041646/http://www.tekkenzaibatsu.com/forums/showthread.php?threadid=95569)
- [Additional combos, posts 2–17](https://web.archive.org/web/20201206041645/http://www.tekkenzaibatsu.com/forums/showthread.php?threadid=96669)

The import preserves explicit counter-hit, opponent-size and positioning restrictions. Omitted uncertain suggestions, cosmetic glitches, quoted duplicates, unexplained wall setups, Tag annotations, and routes with unclear whiff/stance requirements. This is selected coverage, not a complete transcription of every forum page. Community routes have been transcribed and checked for input rendering, not independently verified in an emulator. Source links and forum metadata stay out of the character guides.
