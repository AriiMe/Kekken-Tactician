# Classic game archive status

Tekken 1–5 (including Dark Resurrection in Tekken 5) are connected to the game library, local JSON loader, character routes, prerendering and sitemap. Tekken Tag Tournament 1 remains a draft.

The shared renderer supports moves, combos, grouped launchers, throws, punishers, wall combos and stance entry inputs. Empty sections are hidden. Do not add placeholder inputs or guessed frame data. Shared costumes link to the original fighter’s guide; mimics explain which guide to use.

Tekken 5 and DR share a game page, but have balance and combo differences. DR-only fighters and PS3-only Jinpachi are labeled in their notes.
