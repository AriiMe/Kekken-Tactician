# Tekken Tag Tournament archive expansion

Tag 1 now has accessible roster and character routes, navigation, static HTML and sitemap entries. The 39-entry roster contains 32 independent guides, four shared costumes and three mimics. Character artwork was not supplied; the existing text fallback is used.

Imported self-contained moves and matching frame rows from all 32 character tables. Alternate commands with identical descriptions and frame values share an entry. Hidden moves supplement the main tables. Juggles share launcher lists where possible; complete duplicate routes are removed. Partner-dependent moves and tag combos name the required partner and describe handoffs.

The 70+ damage FAQ supplies guide-reported damage, counter-hit requirements, size restrictions and escape conditions. Its escapable routes live under Recovery Setups. Ambiguous whiff notation and the explicitly uncertain King quick-roll claim were excluded. Tag-class labels describe launch properties, not universal partner compatibility. The Armor King mount exploit is labeled arcade-only and fixed on PS2. Cosmetic glitches and unverified infinite claims are omitted.

Tekken 3 receives **referenceFrameData**, not asserted Tekken 3 measurements. Only matching commands on the same fighter qualify, with a visible notice above each affected guide. The supplied source is a Tag Tournament frame guide and does not establish that Tekken 3 values are identical. Missing values remain missing. Startup excludes command-entry time; stagger advantage is not a guaranteed punish window.

Source consistency checks excluded conflicting frame rows for Baek's Heavy Wave, Wave Needle, Hurricane and non-attacking Baek Hop, Eddy's Flare, King's Flying Cross Chop and Xiaoyu's Shady Lotus. Their move commands remain available. Corresponding Tekken 3 references were also removed.
